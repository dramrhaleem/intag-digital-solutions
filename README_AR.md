## ما تم تسليمه

- **منظومة الشعار:** Horizontal، وStacked، وWordmark، وSymbol، وSmall-size، وFull Color، وReverse، وBlack، وWhite، وAvatar، وApp Icon.
- **نظام الألوان:** ألوان أساسية ومحايدة ودلالية، ودرجات محسنة لإتاحة القراءة، ولوحات ASE/GPL، ومتغيرات JSON/CSS/SCSS، وفحص للتباين.
- **الخطوط:** Poppins للنصوص اللاتينية وIBM Plex Sans Arabic للعربية، مع ملفات الترخيص.
- **اللغة البصرية:** Connected Frame، وPatterns فاتحة وداكنة، و12 Icon مميزة، وKey Visual ومقاساته.
- **القوالب:** PowerPoint وProposal باللغة الإنجليزية، وLetterhead عربي، وBusiness Card، وغلاف عرض، ومنشورات، وStory، وواجهة موقع، وEmail Signature، وFavicon، وWeb App Manifest.
- **دليل الهوية:** الاستراتيجية، وقواعد الشعار، والألوان، والخطوط، وقواعد اللغتين، والصور، والحركة، وعرض البيانات، والتطبيقات، والحقوق، والحوكمة، والأسئلة المفتوحة.
- **ملفات البناء:** إعادة بناء الأصول، والتصيير، وإنشاء ملفات PDF، وتجميع معاينات فحص الجودة.

## سياسة الحقول المؤقتة

يجب استبدال أي نص بين أقواس مربعة، مثل `[NAME SURNAME]` أو `[CLIENT]` أو `[WEBSITE]`، قبل الاستخدام. ولا تتضمن القوالب بيانات قانونية أو بيانات اتصال مختلقة.

## حدود النسخة

- لم يتم اعتماد الاسم العربي القانوني أو نطق INTAG رسميًا.
- لم يُجرَ فحص قانوني للعلامة التجارية أو النطاقات أو المعرّفات الرقمية.
- قيم CMYK تقريبية، ولا توجد درجة Pantone مؤكدة من الشاشة.
- تحتاج ملفات الطباعة إلى ملف المورد، ومساحة نزف، وبروفة، وفحص قبل الطباعة بحسب المورد.
- الـKey Visual أصل تجريبي، ويحتاج توثيق المصدر ومراجعة الحقوق إلى اعتماد قبل استخدامه في حملة عامة.
- ترتيب الخدمات والجمهور والعرض المحوري افتراضات استراتيجية تحتاج إلى التحقق.
- لا يزال معنى «التطوير» غير محسوم: تطوير المنتجات والبرمجيات أم تطوير الأعمال.

## إعادة البناء

يتطلب تشغيل ملفات البناء من جذر المشروع وجود Python وNode.js. وتوجد الإصدارات المطلوبة في `requirements.txt` و`package.json` و`pnpm-lock.yaml`:

```powershell
python source/build_identity.py
node source/render_assets.js
python source/build_favicon.py
node source/render_logo_pdfs.js
node source/render_brandbook.js
python source/build_quick_reference.py
node source/make_pdf_contact_sheet.js
python source/validate_package.py
python source/build_release.py
```

يفترض هذا الترتيب إجراء معاينة بصرية كاملة لملف دليل الهوية بعد تحويله بواسطة Poppler، ثم إنشاء حزمة الإصدار بعد اجتياز الفحص التقني وتوثيق المراجعة البصرية.

يجب تسجيل كل قرار اعتماد مع التاريخ، والمسؤول، والمبرر، والنسخة المتأثرة.
