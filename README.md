## ما في هذا المستودع

الموقع فقط. حزمة التسليم الكاملة — الشعار بكل صيغه، القوالب، ملفات الطباعة، التوثيق العربي، وملفات البناء — تُسلَّم منفصلة.

| المسار | المحتوى |
|---|---|
| `brandbook/` | صفحة الدليل وملف الأنماط |
| `assets/logo` | الشعار بصيغة SVG والفافيكون |
| `assets/key-visual` · `assets/patterns` · `assets/icons` | اللغة البصرية |
| `assets/tokens` | توكنز التصميم: CSS، SCSS، JSON، ومواصفة اللون |
| `assets/fonts` | الخطوط الأربعة وتراخيصها |
| `assets/previews` · `assets/mockups` | معاينات القوالب والموك أب |

## النظام في سطر

الاسم **INTAG** بالحروف اللاتينية في كل السياقات، والوصف وحده يُترجَم. الشعار كتابي بلا رمز تصويري: الاسم خمسة حروف، وأي رمز من حرف واحد يوضع بجانبه يُقرأ تكرارًا. النصّ عربي-أساسي، والوضع الداكن هو الأصل.

## الحركة

الصفحة تطبّق مواصفة الحركة التي تنشرها: المدد `160 · 280 · 560ms` ومنحنيات التسارع تُقرأ من ملف التوكنز، والاتجاه يتبع اتجاه الصفحة، و`prefers-reduced-motion` يُلغي كل حركة غير ضرورية.

## الخطوط

الأربعة تحت **SIL Open Font License 1.1**: Quattrocento · Quattrocento Sans · Amiri · Noto Naskh Arabic. الاستخدام التجاري والتضمين والتعديل مسموح، والبيع المنفرد ممنوع. نصوص التراخيص كاملة داخل مجلد كل خط.

## النشر

كل دفعة إلى `main` تُعيد نشر الموقع عبر GitHub Pages.
